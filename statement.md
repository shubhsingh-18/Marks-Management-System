# Student Information and CAT-1 Result Management System


## Problem Statement

Managing student information and examination marks manually can be time-consuming and prone to errors. There is a need for a simple system that can store student registration details, record CAT-1 marks for different subjects, and generate the student's total marks, average marks, grade, and pass/fail result.
The Student Information and CAT-1 Result Management System is a Python-based console application designed to simplify this process. The system allows users to enter student details and their marks, search for a student using their registration number, and display the student's academic result.

The project aims to provide an easy-to-use and efficient way to manage basic student academic information without requiring a database or complex interface.


## Scope of the Project

The scope of this project is limited to managing basic student information and CAT-1 examination results.
The system includes the following areas:

Storing the student's registration number and name.

Recording marks for three subjects:

Introduction to Problem Solving

Electric Circuits and System

Calculus

Searching for a student using their registration number.

Displaying the student's stored marks.

Calculating the total marks obtained by the student.

Calculating the average marks.

Assigning a grade based on the average marks.

Determining whether the student has passed or failed.

Allowing the user to enter and search for multiple students.

Providing an option to exit the program.

The current version is a console-based application and stores information temporarily while the program is 
running. It does not use a permanent database or graphical user interface.


## Targeted Users

The main users of this project are:

Students – to view their recorded marks, average, grade, and result.

Teachers/Faculty – to enter and review student marks and basic information.

Academic Staff – to manage simple student result information.

Beginners learning Python – as an example of using dictionaries, lists, loops, functions, conditional statements, and user input.


## High-Level Features

Student Registration – Stores registration number and student name.

Marks Entry – Records marks for three subjects.

Student Search – Finds students using their registration number.

Result Calculation – Calculates total and average marks.

Grade Assignment – Automatically assigns grades based on average marks.

Pass/Fail Result – Determines whether the student has passed or failed.

Multiple Students – Allows entry and management of multiple students.

Exit Option – Allows the user to safely exit the program.
